## 1. 产品概况

- **是什么**：Android 天气应用「易得天气」，Jetpack Compose + Material3 实现。
- **核心视觉特征**：
  - 整屏**天气渐变背景**（按天气类型 + 昼夜动态生成，如晴天蓝、阴天灰、雨天深蓝），UI 颜色（文字深/浅、面板透明度）随背景亮度自动反转。
  - 卡片是**半透明毛玻璃面板**（backdrop 模糊），叠在渐变背景上。
  - 大量**圆角卡片**，整体接近 iOS 天气的观感。
- **主要功能模块**：实时天气、逐小时预报、15日预报（曲线/列表双视图）、空气质量、生活指数、气象预警、8 类观测数据、多城市管理（最多 20 个）、城市搜索、自定义卡片排序、自定义天气背景。

## 3. 设计系统约束（请沿用）

| 维度 | 现有规格 | 平板设计要求 |
|------|----------|--------------|
| 背景 | 整屏天气渐变（动态），UI 随亮度反色 | **保持**。大屏背景按当前选中城市的天气渐变铺满整屏 |
| 卡片 | 半透明毛玻璃面板，圆角 **12dp** | 保持圆角与毛玻璃质感；可适度增大圆角到 16dp 提升大屏观感 |
| 卡片外边距 | 左右 **16dp** | 大屏改用栅格 gutter（建议 16~24dp），见 §5 |
| 头部温度 | 92sp（展开）/ 86sp（折叠） | 平板可放大，但避免过分占屏；建议 100~120sp 或改为左对齐 |
| 字体 | 系统默认，bodyLarge 16sp/24 行高 | 沿用，正文不必随屏放大太多，重在「多列」而非「放大」 |
| 圆角面板高度（参考） | 逐小时 132、观测卡 128、空气质量 88（dp） | 大屏保持卡片高度，靠**横向分栏**填满，而非拉伸单卡 |
| 主题 | 支持浅色/深色/跟随系统 | 两种主题都要适配 |

## 4. 适配目标与推荐方案

### 总原则
> **大屏不是"把手机界面拉宽"，而是"用横向空间并排展示更多内容"。**
> 手机（Compact，<600dp）档保持现状 100% 不变；平板/折叠展开（Expanded，≥600dp）启用以下新布局。

### 4.1 天气主页（最重要）

提供三选一，**推荐方案 C**：

- **方案 A（保底）**：内容限宽居中 `max 600dp`，两侧留白。最省事但浪费空间。
- **方案 B（瀑布）**：天气卡片分 **2 列瀑布**（如左列：头部+逐小时+15日预报；右列：空气质量+观测+生活指数）。
- **方案 C（推荐，List-Detail）**：
  ```
  ┌─────────────┬───────────────────────────────────┐
  │  城市列表     │   当前城市天气详情（可滚动）            │
  │ (常驻左栏)    │   ┌──────────┐ ┌──────────┐        │
  │ · 萧山区 29° │   │ 头部大温度 │ │ 空气质量   │        │
  │ · 厦门 26°   │   ├──────────┤ ├──────────┤        │
  │ · 南宁 29°   │   │ 逐小时     │ │ 观测(2列)  │        │
  │ · 北京 19°   │   ├──────────┴─┴──────────┤        │
  │ ...          │   │ 15日预报（整宽）         │        │
  │ [+ 搜索]     │   └────────────────────────┘        │
  └─────────────┴───────────────────────────────────┘
  左栏约 320~360dp，右栏自适应，右栏内部再用 2 列卡片网格
  ```
  - 左栏 = 现有「城市管理」列表（常驻），点选即切换右栏，无需整页跳转。
  - 右栏 = 现有「天气主页」内容，但内部卡片改为 **2 列网格 / 瀑布**填满宽度。
  - 折叠/手机收起时退化为现状单页 + 跳转。

### 4.2 城市管理（独立全屏时）
单列 → **2~3 列卡片网格**（`GridCells.Adaptive`，每卡最小宽约 320dp）。编辑态、左滑删除逻辑保留。

### 4.3 城市选择 / 搜索
- 热门城市：4 列 → 随宽度 **6~8 列**（`Adaptive(minSize≈96dp)`）。
- 搜索结果：单列 → **2 列**，并整体限宽居中（如 max 720dp）避免行太长。

### 4.4 弹窗（生活指数 / 空气质量详情等）
手机贴底全宽 → 大屏改为**居中对话框**，`widthIn(max≈480dp)`；生活指数网格在对话框内可由 3 列升到 4~5 列。

### 4.5 观测数据 / 生活指数网格
本身已是多列，平板上**增加列数**即可（观测 2→3 列，生活指数 3→4/5 列）。

## 5. 栅格与断点建议（供设计参考）

| 断点（屏宽） | 档位 | 天气主页 | 城市网格 | 热门城市列 |
|--------------|------|----------|----------|------------|
| < 600dp | Compact（手机） | 单列（现状） | 单列 | 4 |
| 600–839dp | Medium（折叠展开/小平板竖屏） | 2 列卡片 或 List-Detail | 2 列 | 6 |
| ≥ 840dp | Expanded（平板横屏） | **List-Detail**（左列表+右双列） | 3 列 | 8 |

- 内容区外边距：手机 16dp；平板建议 24dp。
- 卡片间距（gutter）：手机 12dp；平板 16~20dp。
- 右侧详情内容区建议设最大可读宽度，避免单卡过宽。

## 7. 硬性约束清单（务必遵守）

- ✅ 手机竖屏（Compact）布局**保持现状不变**，新方案只在 ≥600dp 生效。
- ✅ 沿用天气渐变背景 + 毛玻璃半透明卡片 + 圆角的视觉语言。
- ✅ 浅色/深色双主题都要可用，文字颜色随背景亮度反转的逻辑不破坏。

- ✅ List-Detail 在收起/手机态要能优雅退化为单页导航。
- ⚠️ 注意状态保留：旋转/折叠不应丢失滚动位置、选中城市、弹窗状态。
